# Company

Layout: `company/<name>/<project>/`. Keep a project's pages together so a code owner can be assigned to the folder. Material about a client stays inside that client's folder.

Everyone with repository access can read every folder here. See the open decision in [AGENTS.md](../AGENTS.md) before adding sensitive client material.

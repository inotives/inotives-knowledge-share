# Generated output

Shareable renderings of work that lives in markdown. Name files `<subject>-<kind>-<YYYY-MM-DD>.<ext>`.

Rules, also in [AGENTS.md](../AGENTS.md):

- Every figure and claim traces to a line in a source markdown page.
- No new numbers; keep `[V]` / `[?]` markers and draft framing.
- Fix the source and regenerate. Never edit only the output.
- Keep files self-contained and small.
